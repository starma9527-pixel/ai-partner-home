📖 技术小白运维指南

日常更新内容只需 3 步：

  1. 打开本页面：在浏览器访问 你的网站地址/admin.html
  2. 修改内容：切换上方标签（打单兵器、赢战MaaS等），编辑表单内容
  3. 发布更新：点击底部「📋 复制代码到剪贴板」按钮，然后：
    1. 打开 GitHub 上的 app.js 文件
    2. 点击 铅笔图标（编辑）
    3. Ctrl+A 全选 → Delete 删除旧内容
    4. Ctrl+V 粘贴新内容
    5. 点击绿色按钮 Commit changes
    6. 等待 1-2 分钟，Netlify 自动部署完成

常见操作场景：

  • 🔄 更新龙虎榜数据：切换到「龙虎榜」标签，修改排名、分数
  • 🎬 添加直播培训：切换到「打单兵器」标签，在「直播培训」区域添加
  • 🚀 增减赛道：切换到「赢战MaaS」标签，添加或删除赛道卡片
  • 📄 添加知识库文档：切换到「打单兵器」标签，在「知识库」区域添加
  • 💬 管理留言：切换到「回音壁」标签，添加或删除留言
